# 真实感生图提示词

把“像普通手机拍下的真实生活照片”转化为可执行的几何、材质、受力与成像约束。优先维持用户指定的人物和照片结构，按需加入细节；不要把“真实感”理解为自动美化、换体型或堆叠噪点。

## 确定任务与参考分工

- 先确认交付物：只要提示词时只输出提示词；明确要求生成或编辑图片时，把整理后的指令交给可用图像工具。不要把提示词请求擅自变成生图，也不要声称文字指令已修改图片。
- 从当前请求判定新图生成、参考图扩展、原图真实化、局部身份融合或其他局部编辑。沿用当前对话已确认的条件，不重新收集相同信息。
- 实际查看可访问的参考图片；只有文字描述时按描述写，不假装已看图。没有参考图也能完成通用生图提示词。
- 多图分别指定底图、面部身份、身材比例、服装或风格的用途。遵从用户的图序与分工，不固定“图一身份、图二底图”。缺少参考分工且会改变编辑对象时才问一个必要问题。
- 人物身份与身体设定分开处理。身份图不自动决定身材、年龄感、发型或构图；遵从本次明确分工。不要把某一次人物姓名、身高体重、胸围、沙漏体型、衣服或房间写成通用默认值。
- 提炼“必须保留、允许修改、目标效果”三组条件，内部使用即可。当前明确要求优先于本技能默认值。

## 选择编辑边界

| 任务 | 指令重点 |
| --- | --- |
| 新图生成 | 明确主体、服装、场景、摄影关系、姿态与光线，再写与画面有关的真实感细节。 |
| 原图真实化 | 默认保留身份、体型、姿势结构、服装、手机、镜子、背景与构图；在允许区域内修正纹理和成像。 |
| 局部编辑 | 指明可编辑区域和必要过渡范围；保留其余区域，局部匹配原图光照、曝光、白平衡、锐度与颗粒。 |
| 局部身份融合 | 由底图决定头部位置、大小、角度、透视及身体；身份参考仅提供所需面部特征，不直接贴入另一角度的整颗头。 |
| 扩图或第三人称扩展 | 将新露出区域视作合理补全，不冒称还原原图不可见结构；只在用户要求的范围内改变构图或摄影关系。 |

把“保留”写成目标，不承诺生成模型能做到像素级锁定或百分之百身份一致。若工具确实支持局部蒙版，可用蒙版限制编辑；不要虚构工具能力。

## 保持自然身体比例

- 以底图或指定身体参考为准，保留头身关系、肩宽、躯干长度、腰臀位置、腿部体量、自然软组织和年龄感。
- 默认不瘦脸、不瘦身、不削腿、不拉长双腿、不缩头、不抬高腰线或裆部、不收窄骨盆，也不通过缩短躯干制造长腿。
- 检查胯—膝—脚踝连接与透视缩短是否合理；保留坐姿、俯拍和交叠导致的真实缩短，不用统一“标准头身比”覆盖参考图。
- 全身入镜靠合适取景范围与留白实现，不为塞下鞋子压缩下肢。只有明确授权扩图、调整机位或新图构图时才扩展画幅；“构图完全不变”与“补出原图外完整鞋子”冲突时，指出冲突并请求选择，或先交付不扩图的保守版本。
- 不从单张遮挡图推断准确身高、体重、杯型或不可见腿长；不得把这些推断当事实。

## 继承摄影关系、遮挡与视线

- 先区分镜自拍、普通前置自拍、第一人称向下俯拍与第三人称。未要求改变时继承原图摄影关系。
- 镜自拍保留镜面边界、持机手与手机方向、手臂可达范围、反射空间和遮挡层次。手机在镜中合理出现，镜框与地面透视一致；不要让持机手同时执行不可能的动作。
- 用位置关系描述机位、倾斜、拍摄距离与取景。原图编辑不强加新焦距；新图默认自然手机透视，避免夸张广角，不同时堆叠互相冲突的焦距数值。
- 明确“看手机屏幕”“看镜中自己的眼睛”或“看镜中手机镜头”。不把三者写成同一个视线目标，也不机械地把镜自拍写成直视画外相机。
- 保留用户要求的遮脸关系。仅要求真实化时不补画被手机遮住的五官。
- 若要求遮住嘴与下巴、露出上半脸，写清手机反射上缘位于眼睛下方且覆盖嘴与下巴，两眼不被遮住；根据底图角度细化，不用笼统“半遮脸”。
- 若要求完整露脸，允许且明确列出手机、持机手及必要局部手臂的最小调整；同时删除“手机位置完全不变”等冲突句。保留眼镜及其遮挡反光，不擅自去掉眼镜。

## 按物理关系写真实感

只选与画面和编辑范围有关的细节。需要可直接改写的片段时，读取 [references/prompt-patterns.md](references/prompt-patterns.md)。

### 皮肤、发丝与画质

保留与画面分辨率、距离相称的细腻皮肤纹理、轻微毛孔和自然色差，允许关节及受压处颜色变化；不添加粗大毛孔、伤痕或额外年龄特征。保留合理碎发和发束层次，不机械添加凌乱。局部脸部的清晰度、噪点与肤色应和身体、环境一致，不出现单独超高清的脸。

### 丝袜

沿用指定颜色、厚薄、哑光或光泽、透肤程度。用织物与皮肤叠加、曲面和光线引起的透肤差异、弯曲处细褶、受拉伸处纹理变化描述材质，不画成腿部油漆或塑料。

不要把旦数当成固定透光率：厚度、织法、颜色、拉伸和照明共同决定观感。不要把中厚哑光袜写成油亮薄袜；肤色薄袜也应保留轻微织物存在感。全身远景不要求可见每根纤维，厚袜遮住的皮肤不强行显露毛孔。只在相关区域描述丝袜进入鞋口的包裹、压痕与接触关系。

### 针织与其他衣料

按实物区分粗针织、细针织、罗纹和衬衫布料。体现织纹尺度、衣料厚度与自然垂坠；肘部、腰部、肩部及持衣处的褶皱服从姿势和受力。避免贴图般重复纹理、均匀硬褶或针织材质变橡胶。衣服厚度不能靠削薄身体实现。

### 支撑、重心与接触阴影

说明实际支撑位置：站姿的承重脚、坐姿的座面与脚部、蹲姿的前掌或脚跟。只在真实接触处产生随光线方向变化的紧密阴影，离开接触点逐渐变软；不要用统一黑边描轮廓。

高跟鞋按姿态描写前掌、鞋跟与地面的接触；脚尖点地或抬脚时不强迫每个接触点落地。手指压住衣料、身体压住座面时，形变和阴影相互对应。不要用加深阴影掩盖悬空或错误连接。

### 轻微姿态不对称

允许姿态调整时，使用有支撑依据的承重腿紧张、非承重腿放松、轻微肩高差和骨盆倾斜。保持幅度克制，避免标准模特拗姿或明显歪斜。

若姿势、身体轮廓或像素位置被锁定，只保留已有不对称，通过已有受力对应的材质细节提升真实感；不偷偷改变肩高、骨盆、关节或重心。“姿势不变”不是修改姿势的许可。

### 光线与手机成像

继承底图主光方向、软硬、曝光与白平衡，保持投影和镜面反射一致。新图根据场景选一个可信光源，存在环境光时再描述混合光。允许适量暗部噪点、局部锐度差异和轻微曝光不均，不把脏镜面、低清晰度、压缩损伤、虚焦或颗粒设为必选项。不要为了生活感破坏照片。

## 组织可直接使用的提示词

默认使用中文，按任务复杂度写一段或几个短段落：

1. 任务与参考分工、必须保留的内容。
2. 允许修改的区域或要生成的画面内容。
3. 自然比例、摄影与遮挡关系。
4. 本图最关键的材质、受力、光影与成像细节。
5. 少量针对性负面约束。

普通任务尽量约 300–600 字，复杂多图编辑以完整清晰为准，不为凑字数省略边界。用户要求完整版本、短版、JSON、英文或多方案时遵从其格式。最终提示词独立可用，不写“同上”或未解释的代号，不附整套方法说明。未给定但可合理默认的设置直接处理，避免反复确认。

负面约束按需精简为：不要过度磨皮或塑料皮肤，不拉腿瘦身，不要失真反射、漂浮接触、过度 HDR、过强锐化降噪、CG/3D 或商业影楼感。不要反复重复同义禁止项；每个关键目标应有相应的正向描述。

## 交付前检查

- 是否把新图、局部编辑或扩图混为一谈？各参考图职责是否明确？
- 是否引入未授权的脸部、身体、服装、背景、遮挡或视线变化？
- 是否出现“姿势完全不变却调整骨盆”“手机不动却露全脸”“不扩图却补出画外鞋子”等冲突？
- 人体节点、持机、反射、接触阴影与材质受力是否相互一致？
- 是否让丝袜呈现油漆感，或给针织/皮肤添加超过画面尺度的纹理？
- 局部编辑的光线、颗粒、肤色和清晰度是否匹配整张照片？
- 是否将普通手机真实感误写成影楼精修，或误写成强噪点低质照片？

修正可自行解决的冲突再交付。存在无法同时满足的硬条件时，简短指出具体冲突，只问影响结果的那一个问题。不保证模型绝不漂移；如果用户带回结果图，按实际可见问题给最小范围修订，不重新设计全部内容。
