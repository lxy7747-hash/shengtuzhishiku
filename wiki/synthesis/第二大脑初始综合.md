# 第二大脑初始综合

## 当前综合

本 vault 的第二大脑架构把 LLM 从“临时回答问题的检索器”转变为“持续维护知识代码库的代理”。核心转变是：知识不只存在于 raw sources 或聊天记录中，而是被编译进一个由 Markdown 页面组成的 [[wiki/concepts/持久 Wiki.md]]。

## 初始判断

- 对当前 vault 来说，`index.md` + `log.md` 足够作为早期导航系统。
- 暂不需要复杂搜索或向量数据库；当页面数增长后再评估。
- 最重要的初始习惯是：每次 ingest 都更新相关概念页、index 和 log。

## 当前架构

- [[AGENTS.md]]：代理规则。
- [[index.md]]：内容地图。
- [[log.md]]：时间线。
- [[wiki/workflows/Ingest 工作流.md]]：首个可执行工作流。
