# 客观反推工作流

## 目的

将用户上传的参考图片转换为**客观、结构化、高保真且解耦**的生图提示词。核心理念是**“人物身份/身材”与“视觉要素（穿搭/姿势/镜头/环境）”彻底分离**。

## 对应 Skill

- **对应 Skill**：`objective-image-prompt`（已安装至 `.agents/skills/` 与全局配置）。

## 核心反推逻辑

$$\text{固定人物身份 / 身材母版} + \text{参考图视觉结构（服装/动作/镜头/场景）} = \text{最终人物生图提示词}$$

- **参考图负责提取**：发型、配饰、服装、材质、姿势、动作、遮挡关系、拍摄方式、构图、景别、机位、透视、场景、背景物、光线、摄影质感。
- **参考图默认不提供身材**：人物身材统一剥离，采用固定母版（赵凤丽 168cm / 65kg 丰满型沙漏身材）或用户本轮指定身材。

## 身材优先级阶梯

1. 用户本轮明确指定的新身材参数。
2. 用户明确指定的人物身材参考图。
3. 知识库固定人物身材母版（[[wiki/concepts/人物身材基线.md]]，赵凤丽：168cm / 65kg / C杯 / 饱满有张力臀 / 肉感大腿）。
4. 当前参考图中的体型（仅当前三项皆无时作为弱参考，且禁止自动修图、瘦脸拉腿）。

## 反推输出与分层

反推结果直接对齐 [[wiki/concepts/GPT Image 结构化提示词 schema.md]]，产出包含：
- 画面类型与画幅
- 主体客观特征（应用固定母版）
- 服饰与物理材质
- 环境与空间关系
- 摄影技术参数（焦段、景深、手机/相机质感）
- 精准针对性负面提示词
