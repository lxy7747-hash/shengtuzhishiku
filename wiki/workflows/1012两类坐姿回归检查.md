# 1012两类坐姿回归检查

本页是1012的候选回归规格与证据记录入口，不是已执行图片测试。已完成两份原文和四张现有图片的核对；F12、F13生成、复现与验收均未执行。检查项根据原文目标和本次观察缺口整理，不能倒写为原作者已验证结论。

## 基准与来源分工

- 盘腿：[[提示词/06-案例复盘/1012/2.txt]]；观察图1.png为盘腿、2.png为并膝，均非已确认输出。完整身份、体量和场景来源在新任务中另行记录。
- 并膝：[[提示词/06-案例复盘/1012/融合/1.txt]]；图一[[提示词/06-案例复盘/1012/融合/图一.png]]负责身份、发型、眼镜、自然体量及手机摄像头样式，图二[[提示词/06-案例复盘/1012/融合/图二.png]]负责场景、服装、坐姿、构图和光线，挡脸文字覆盖图二原手机位置。
- 公开回归依据：[[wiki/sources/2026-10-10 - 学院风蹲姿扩展与T06验证基准.md#T06与验收依据]]及[[wiki/concepts/实战案例提示词片段库.md#F08 验证说明与检查项]]，核对日期2026-10-13。这里沿用仓库已公开的文字核对与图片测试分离、可见证据和关键失败原则，只新增1012定向规格，不改既有T编号或测试文档。

## 两个互斥动作分支

| 分支 | 腿部与躯干 | 空手职责 | 支撑与接触目标 | 不能混入 |
|---|---|---|---|---|
| P：盘腿（F12） | 双膝外展、小腿向前内折并交叠；骨盆稳定、腰背自然挺直 | 轻放身前腿间或交叠处，不承担后撑 | 臀部坐垫，交叠腿脚接触自然，不要求两个脚底像并膝分支一样全部接地 | 并膝抬起、双脚前方并排、空手后撑、上身后仰靠掌承重 |
| S：并膝支撑（F13） | 双膝靠近并向胸前抬起、小腿向前下方；上身轻后倾 | 向身体侧后方撑垫，分担重量 | 臀部、掌面、两脚与垫面相容；两白袜脚并拢、朝镜面、完整入镜 | 双膝外展、小腿交叠、空手腿间放松、两手同时举机 |

画面左右和身体左右不等价。原盘腿文字写右侧持机，现有1.png和2.png均左侧持机；融合图一左侧持机、图二右侧持机。复测记录所选持机手，并以“持机手 / 空手”分工，保持配饰所属手腕，不用笼统“照图二全部动作”交换身份图的手部职责。

下表是本次人工文字核对，单列结构问题，不算模型执行通过。

| 检查 | 当前核对证据 | 复用时的处理 |
|---|---|---|
| 动作分支唯一 | 两份原文分别定义P与S；2.txt明确排除并膝竖起 | F12、F13二选一，连同空手和躯干受力整体替换，不把两者拼接 |
| 双图优先级 | 融合版明示图一身份和体量、图二场景和姿态；通用双图工作流默认图序相反 | 记录实际图片文件及角色，按本次定义优先；不强加固定身材母版或迁移场景图脸型 |
| 盘腿输入完整性 | 2.txt没有身份、身材、画幅和完整背景定义 | F12是片段，先补明确基准；若选并膝图作场景参考，另写盘腿文字覆盖其坐姿 |
| 手机身份与遮挡 | 融合版指定图一摄像头、粉色花纹壳；遮挡文字优先于图二位置 | 原手机结构与握持连贯，允许实现局部挡脸所需的小幅移机，不同时锁死坐标 |
| 双眼与遮挡比例 | 两原文要求双眼可见及约35%–45%；原盘腿同时描述手机在眼鼻高度 | 保留原目标回链；候选片段用手机在镜中与一侧下半脸重叠、上缘避开双眼的可观察关系。比例仅作近似目标，不虚构精确测量；无法兼容时记录问题并修订新版本，不补画双眼或声称全部满足 |
| 脸部露出边界 | 原文只要求遮部分脸颊、嘴角或下巴，非1009的全遮嘴下巴，也非F03的单眼 | 按1012局部遮挡核验，允许其余嘴唇或下巴轮廓可见；不继承其他案例硬边界 |
| 输出形式与范围 | 融合版一张场景重建；盘腿原文未规定数量 | 候选定向复测每支输出一张独立图；双图场景重建与仅基于已完成场景的姿态编辑分别记录授权范围 |

## 图片回归检查项

实际执行前固定输入图文件版本、身份来源、场景来源、完整提示词、画幅与输出尺寸，并记录工具版本和可用设置。每次复测重新引用同一组原始基准，不让上一张结果成为唯一身份来源。查看全图及脸与手机、髋膝踝、空手接触、双脚与垫、背景器械的必要局部。

| 检查项 | P：盘腿的可见证据 | S：并膝支撑的可见证据 | 关键失败或不可验证边界 |
|---|---|---|---|
| 参考分工与身份 | 与本次明确的身份图比较可见眉眼、脸型轮廓、发型、眼镜和年龄感 | 与融合图一比较同类锚点；图二的束发、脸型与未佩戴眼镜外观不污染身份 | 换脸、混脸、发型或镜框漂移为关键失败；遮住的五官不可验证，不补脸 |
| 身体体量 | 头肩、手臂、躯干、大腿体量与本次基准相容，盘腿挤压自然 | 保持图一可见体量，屈膝透视缩短自然，无缩头、瘦腰或拉腿 | 未指定基准不能判比例保持通过；图一裁切的完整小腿足部比例、准确身高体重不可验证 |
| 腿部拓扑 | 两条腿各自髋—膝—踝连续；膝向两侧展开、小腿前交叠 | 两膝贴近抬起，两小腿向前下方延续，双脚并排在前 | 混合盘腿与竖膝、断腿、多余腿脚、反折或穿模为关键失败；被遮连接标不可验证 |
| 重心与接触 | 臀垫接触、骨盆稳定；空手轻放腿间，交叠处受压与阴影协调 | 上身轻后倾，空手掌面贴垫，肩肘腕受力方向连贯；臀和双脚接垫 | 悬浮、掌腕穿垫、后倾却无可行支撑为失败；静态图不量化重心、力或全部足底接触 |
| 双手职责 | 原持机手举机，空手只轻放腿间 | 一手举机、另一手向侧后撑垫 | 同手同时持机与撑地、空手职责混用、多余手掌或手指为关键失败 |
| 手机与局部遮挡 | 粉色手机，屏幕向本人、背部向镜；遮一侧脸颊及部分下半脸 | 花纹壳与图一摄像头结构保持，文字挡脸覆盖图二脸侧位置 | 手机悬浮、穿脸、额外手机、露全脸、挡住双眼或超过半脸为失败；35%–45%无测量记录不判精确达标 |
| 眼神与头部 | 头轻朝持机侧、下巴稍抬、可见双眼看屏幕 | 头轻偏手机、可见眉眼与屏幕朝向相容 | 不强制角度实测；远侧眼或视线被遮挡、像素不足时记不可验证 |
| 服装材质与足部 | 灰罗纹袜套随交叠压缩，白袜脚自然横放；其他衣服来自本次完整配方 | 酒红上衣、米白不透裤、灰针织袜套和白棉袜，屈膝衣褶与双脚方向相容 | 袜套变靴子/丝袜、丢白袜、裤子变裙等为失败；真实纤维成分不凭外观认证 |
| 镜面与构图 | 依据新任务实际画幅，不能从2.png强加3:4；手机、手与身体反射协调 | 接近3:4，人物中下部、上方留背景、头顶至白袜尖完整；器械可边缘裁切 | 改为第三人称、重复人物、错误镜像、为入镜压腿为关键失败；未见镜框不等于严格镜面几何已确认 |
| 场景与编辑范围 | 依本次选定场景保持，仅姿态及必要手机、衣褶、投影联动 | 按图二重建夜窗、帘、木地板、器械与垫；身份沿图一 | 不能把双图换场景任务判成越界换装；也不能以换场景为由替换身份或体量。无像素对照不宣称背景锁定 |

每次图片测试记“通过 / 失败 / 未执行”；执行后的各检查项记“通过 / 失败 / 不可验证”并附具体证据。不可见证据不计通过，有关键失败不能用美观抵消；尚无输出时全部保持未执行。
