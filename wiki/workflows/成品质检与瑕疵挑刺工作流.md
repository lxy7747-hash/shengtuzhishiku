# 成品质检与瑕疵挑刺工作流

## 1. 背景与核心目标

AI 生图并非一次性完成的过程。由于随机种子和扩散模型的不确定性，即使输入了完美的提示词，生成的成品图像中仍经常暗藏各种 AI 特征瑕疵：
- **AI 塑料假面感**：过度光滑磨皮、缺少原生相机毛孔与传感器微噪点。
- **肢体与身材畸变**：不自觉地拉长腿变“九头身筷子腿”、削尖下巴、抹去 65kg 沙漏肉感。
- **物理力学违规**：细高跟鞋底悬空、缺少紧实锐利的地面接触硬阴影（contact shadow）、鞋跟变成粗跟或带有厚重防水台。
- **道具失真幻觉**：手中手机背面出现第三颗甚至第四颗怪异镜头或多环模组。

本工作流通过引入 **法医级成品质检台 (Quality Auditor & Fixer)**，由视觉多模态大模型对照模特 **赵凤丽 DNA** 及物理力学准则进行全方位挑刺体检，输出 0-100 健康评分与一键局部修复指令（Fix Prompt），形成“出图 -> 质检挑刺 -> 修复重绘 -> 再次出图”的完整品质闭环。

## 2. 六维法医级物理体检准则

| 质检维度 | 考核标准 | 常见翻车表现（挑刺重点） | 判定通过标准 (Pass) |
| :--- | :--- | :--- | :--- |
| **1. 模特身材真实感 (Body Proportions)** | 168cm / 65kg，丰满型沙漏身材，自然适中 C 杯，腰臀比 0.7，大腿匀称肉感。 | 出现非自然长腿拉伸特效、暴瘦筷子腿、过度骨感或尖下巴蛇精脸。 | 保持健康微肉感与真实成熟女性骨架比例，无拉腿畸变。 |
| **2. 鞋跟受力与接触阴影 (Footwear Physics)** | 浅口尖头修长鞋楦，8cm 垂直极细金属细跟，无前防水台。鞋底与地面必须有坚实深邃受力硬阴影。 | 鞋底悬浮无阴影、鞋跟莫名变粗、出现坡跟或前防水台。 | 鞋跟垂直受力，鞋底与地面紧实相切，存在深色硬边缘 contact shadow。 |
| **3. 手机硬件与双摄规范 (Phone Hardware)** | 手机背面严格锁定小型圆角方形斜对角双摄，强制 2 颗纯黑大镜片。 | 出现第三颗/第四颗假镜头、多环 Pro 镜头或排列散乱。 | 严格只有 2 颗黑色大镜头，呈斜对角排列，外框规整无光晕衍射。 |
| **4. 皮肤原相机去磨皮 (Skin Texture)** | 24-28mm 手机原相机直出质感，面部与手部保留微孔与毛细纹理，关节处有健康色差。 | 假面塑料瓷肌、无毛孔过度平滑、过度高光油光。 | 微弱暗部噪点与细腻毛孔自然存在，关节骨节有微弱自然色阶。 |
| **5. 面料与丝袜微应力 (Fabric Tension)** | 20D 哑光微透黑丝，天鹅绒高弹密织，大腿受形体拉伸微透红润肉感且无反光油感。 | 丝袜反光油腻假亮、织物紧绷无垂坠重力、无拉伸透肉渐变。 | 哑光微雾面质感，曲面拉伸处自然显露红润健康肉色渐变。 |
| **6. 空间透视与光学色温 (Scene Lighting)** | 真实玄关穿衣镜，3500K 暖白筒灯柔和垂直下打，地砖拼缝透视真实，保留生活微杂物。 | 光源方向互相冲突、镜中倒影空间与外部不一致、影楼死白假光。 | 顶光方向统一，穿衣镜具备真实梯形透视，地砖缝隙走向收缩自然。 |

## 3. 质检评级系统 (0-100 分)

- **S 级（93 - 100 分）· 殿堂级真实感**：几乎无破绽的极品大片，完全摆脱 AI 感，可直接商用或发布。
- **A 级（85 - 92 分）· 高分优质作**：整体优秀，但存在细微力学瑕疵（如鞋底接触阴影微弱或局部微磨皮）。
- **B 级（70 - 84 分）· 轻微 AI 瑕疵**：存在明显违规项（如鞋跟微粗、手机有轻微多环杂光），建议执行局部重绘。
- **C 级（< 70 分）· 严重失真翻车**：存在严重拉长腿畸变、假面塑料皮或违规三摄，需推倒重做。

## 4. 逆向修复指令 (Fix Prompt) 生成与流转

质检台检测到瑕疵后，会自动生成专门用于局部重绘（Inpainting）或重新提示词出图的高精度指令：

```
[Inpainting / Fix Prompt 范例]
局部精准物理修正重绘：保持人物赵凤丽（168cm/65kg沙漏身材）面容、黑色羊毛高领针织衫与20D微透黑丝不变。
强化足部鞋跟物理受力：8cm尖头极细高跟鞋底与大理石地面紧密接触相切，生成深邃锐利的重力接触硬阴影（contact shadow），完全消除浮空感；
微调手持手机背面镜头模组，纯黑双镜片边缘利落干净绝无杂散反光与第三颗假镜头；
皮肤表层增加24mm原相机直出微孔质感与微弱暗部噪点，去磨皮，真实生活质感。
```

点击 **`🎨 携带此修复指令直接重新出图`**，系统将自动拉起在线生图面板并自动填充该修复指令，实现一键迭代提质。
