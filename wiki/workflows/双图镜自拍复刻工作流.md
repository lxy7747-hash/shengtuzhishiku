# 双图镜自拍复刻工作流

## 目的

将镜自拍参考图的拍摄结构写成完整中文提示词，配合生图时上传的人物底图使用。核心目标是**“结构复刻 + 人物替换”**：保留参考图中的构图、姿势、穿搭与环境，将目标人物（赵凤丽或指定底图）自然置入该生活化镜自拍场景中。

## 触发与定位

- **对应 Skill**：`dual-reference-mirror-selfie`（已安装至 `.agents/skills/` 与全局配置）。
- **输入机制**：
  - **图一（场景参考图）**：提供画幅、机位、镜面透视、姿势动作、服装穿搭、镜子类型与环境光线。
  - **图二（人物底图 / DNA）**：提供面容、发型、肤色及可见身体特征（默认结合赵凤丽 168cm/65kg C杯身材母版）。

## 核心职责与优先级划分

| 内容维度 | 来源 | 规则与边界 |
|---|---|---|
| 构图、画幅、机位、镜面透视 | 图一（参考图） | 横竖幅真实还原，不固定套用竖屏全身；保留镜面真实反射与透视 |
| 头部姿势、视线、肢体动作、手机遮挡 | 图一（参考图） | 提取动作骨架与前后遮挡关系；**图一面部绝对不参与身份提取**，严禁融脸 |
| 穿搭、袜鞋、配饰 | 图一（参考图） | 忠实还原款式、材质、褶皱与垂坠感，按目标身材适配版型 |
| 镜子、环境、杂物、光影 | 图一（参考图） | 保留生活化杂物与环境光温，不做多余滤镜或刻意清场 |
| 面容、五官比例、年龄、发型发色 | 图二（底图/DNA） | 保持图二人物身份一致性，不预设陌生五官，自然融入图一光影与视角 |
| 人物体量与身材 | 模特 DNA / 基线 | 以可见信息优先；不足部分采用赵凤丽基准（168cm/65kg，C杯，腰臀比0.7，匀称肉感大腿） |

## 九段式提示词输出规范

生成最终提示词时，按以下结构依序组织：

1. **任务定义**：明确以本次上传底图为唯一人物外观依据，生成真实智能手机拍摄镜自拍。
2. **参考职责**：明确文字负责环境/姿势/穿搭，底图负责面容发型。
3. **人物身份**：强调同一人物一致性，自然适应图一拍摄视角与遮挡。
4. **人物身材**：以底图或赵凤丽身材母版为准，锁定真实体量，严禁拉腿瘦身。
5. **构图与姿势**：画幅占比、留白、四肢空间关系、持机高度及手机遮挡具体边界。
6. **穿搭细节**：衣物版型、真实面料拉伸状态、鞋袜与饰品。
7. **镜子与环境**：镜形、镜框材质、空间纵深与背景物体分布。
8. **光线与手机摄影质感**：24-28mm 主摄广角、深景深、传感器微噪点、自然皮肤纹理与毛孔。
9. **负面约束**：不混脸、不拉腿、不缩头、不改变发型、不磨皮、无塑料感、无广告级商业打光。
