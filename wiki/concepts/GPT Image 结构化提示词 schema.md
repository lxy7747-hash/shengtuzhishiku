# GPT Image 结构化提示词 schema

## 定义

这是本库两份 GPT Image 模板共用的提示词骨架：把画面拆成**六层**，每层用客观、可核验的物理描述填写，而不是审美形容词。两份实例完全相同地使用了它——[[提示词/02-提示词模板/GPT Image提示词模板/酒店大堂.md]] 与 [[提示词/99-临时收集/临时收集.md]]。

它的价值不在某个具体模板，而在**结构本身可复制**：换掉字段值即可产出风格一致、变量受控的新模板。

## 完整结构

```text
"提示词结构": {
  "强制约束指令": "...",
  "主体客观特征": {
    "面部物理特征": "...",
    "体态物理特征": "...",
    "毛发形态": "...",
    "神态与视线": "..."
  },
  "服饰与物理材质": {
    "衣物形态": "...",
    "物品细节": "..."
  },
  "环境与空间关系": {
    "物理场景": "...",
    "空间深度": "..."
  },
  "摄影技术参数（客观物理描述）": {
    "光影物理属性": { "光源方向": "...", "光质硬度": "...", "光比与反差": "..." },
    "摄影介质与质感": { "成像介质": "...", "噪点与锐度": "..." },
    "构图与镜头语言": { "景别与视角": "...", "色彩倾向": "..." }
  }
}
```

## 逐字段用途

| 层级 | 字段 | 这一层在解决什么 |
|---|---|---|
| 1 | 强制约束指令 | 把最容易漂移的两件事写死：**参考图一致性**（脸型／五官／身材必须严格参考 `@Image`）与**全局否定词表**（不拉腿、不瘦腿、不瘦脸、不缩胯、不磨皮、不改年龄感、头身比例协调）。放在最前，充当整条提示词的总纲 |
| 2.1 | 面部物理特征 | 用可核验的几何描述替代「漂亮／精致」：脸型（偏鹅蛋脸）、下颌线走向、颧骨是否突出、肤色深浅、眉形与眉色、眼型（杏眼）与眼距、双眼皮、鼻梁与鼻头、唇厚与唇色 |
| 2.2 | 体态物理特征 | 描述**姿势与重心**，而非静态身材：坐在什么上、身体朝向、双腿如何交叠、手放在哪里、重心偏移、肢体轻微不对称 |
| 2.3 | 毛发形态 | 发色、长度、扎法、贴合程度、碎发位置、光泽度 |
| 2.4 | 神态与视线 | 视线落点、表情强度、面部肌肉状态、情绪浓度 |
| 3.1 | 衣物形态 | 款式 + 结构 + 面料物理属性：领型、袖长、版型贴合度、反光程度、褶皱与垂坠。丝袜等特殊材质在此写反光层次与透肤感 |
| 3.2 | 物品细节 | 配饰与手持物，具体到型号（如「橙色 iPhone 15 Pro Max」） |
| 4.1 | 物理场景 | 地点 + 地面材质 + 墙面 + 家具 + 装饰，逐项可核验 |
| 4.2 | 空间深度 | 人物在画面中的位置、前景／中景／背景分层、背景是否虚化、纵深判断依据 |
| 5.1 | 光影物理属性 | 光源方向、光质软硬（阴影边缘清晰度）、光比与反差、亮部是否过曝、暗部是否死黑 |
| 5.2 | 摄影介质与质感 | 由什么设备拍摄、什么画幅、色彩还原倾向、噪点量与锐度、是否存在手机压缩或算法平滑痕迹 |
| 5.3 | 构图与镜头语言 | 景别、视角高度、俯仰关系、主体在画面中的位置、整体色调倾向 |

## 为什么这样分层有效（解释）

1. **约束与描述分离**：第 1 层管「不许变什么」，第 2–5 层管「要变成什么」。两者混写时，否定词容易被后面的细节淹没。
2. **客观化替代形容词**：写「下颌线自然收窄」优于写「脸很精致」，因为前者可核验、可复现、可局部替换。
3. **为镜头语言留出独立槽位**：第 5 层让「像随手拍的手机照」和「像商业大片」可以由同一份主体描述派生，只换技术参数层。
4. **变量边界清晰**：要换场景只动第 4 层，要换画风只动第 5 层，主体 DNA（第 2 层）保持不动即维持角色一致性。

## 复用方法

1. 第 1 层：复制既有否定词表，仅在目标变化时增删。
2. 第 2 层：人物 DNA 的稳定部分（见 [[wiki/concepts/人物身材基线.md]]）从这里复用，不要每次重写。
3. 第 3–4 层：按本次任务替换，是主要变量区。
4. 第 5 层：先决定「要什么拍摄介质」，再倒推光影与构图参数。

## 待验证

- 分层 JSON 与单段自然语言在 GPT Image 上的实际效果差异**没有对比数据**，本页只做结构描述，不声称 JSON 更优。
- 两份实例的字段是否穷尽、有没有更细的可用层级（如镜头焦段、输出比例），笔记中未体现。
- 该 schema 是否对 GPT Image 之外的模型同样有效，未验证。
