# 人物身材基线

## 定义与角色档案

本库核心模特**赵凤丽**的身材标准描述与配套否定约束。它的作用是让提示词结构中的「主体客观特征」在每次生成时复用同一套体态锚点，锁定角色身材与比例，防止跨批次生成时出现身材变形或漂移。

### 角色基准档案：赵凤丽

- **姓名**：赵凤丽
- **基础定位**：AI 服装模特 / 写真模特
- **身高 / 体重**：168cm / 65kg
- **体型风格**：丰满型沙漏身材（曲线明显、健康匀称、保留真实肉感与身体厚度）
- **胸部**：自然适中 C 杯，不过于丰满夸张，胸廓结构自然真实
- **腰部**：相对紧实平坦，腰线位置较高，腰腹无明显赘肉但不过度极端收缩
- **臀部**：自然饱满、健康有张力，臀胯落差清晰，圆润饱满
- **腿部**：大腿匀称肉感（线条饱满紧致），小腿纤细修长，腿型笔直健康，重心稳固

## 正向基线

### 体量与整体比例

年轻成年女性，高挑匀称，体态自然挺拔，**真实亚洲女性服装模特比例**。整体呈自然沙漏型（含轻度梨形倾向），保留自然骨架与真实身体厚度。

### 上半身

- 肩颈：肩宽适中，肩颈线条清晰，锁骨区域自然显露。
- 手臂：修长，肌肉线条柔和，无健身肌肉感。
- 胸部：比例中等偏丰满，胸廓自然。
- 腰部：明显收紧，腰线位置较高，形成清晰的腰臀落差。

### 下半身

- 骨盆宽度明显，胯部饱满，臀部圆润且有体积感。
- 下半身比例较长但须真实。
- 大腿饱满紧致，小腿纤细修长，膝盖与脚踝比例自然，腿型笔直。
- 双腿自然并拢站立时大腿内侧接近。

### 多视角一致性

- **侧面**：身体前后厚度自然，胸、腰、臀形成明显但真实的 S 型曲线；背部挺直，腹部平坦，臀部后翘但不过度夸张。
- **背面**：肩背窄而平直，腰部收紧，臀胯宽度明显，臀部饱满圆润，大腿后侧线条自然。

## 否定约束（成对使用）

正向描述与否定约束是一一对应的：每写一条「是什么」，就补一条「不许变成什么」。

| 正向锚点 | 对应否定 |
|---|---|
| 高挑匀称 | 不要拉长腿部、不要瘦腿 |
| 胯部饱满、臀部有体积 | 不要缩小胯部、不要削弱臀部体积、不要夸张漫画化丰臀 |
| 上半身纤细但不干瘦 | 不要生成纸片人身材、不要改变真实人体厚度 |
| 腰部收紧但自然 | 不要让腰部细得不自然、不要瘦腰过度 |
| 肩宽适中 | 不要让肩膀过窄 |
| 真实骨架与重心 | 不要破坏真实重心 |
| 面部一致（全局约束） | 不要改变脸型、不要改变五官比例、不要瘦脸、不要过度磨皮 |
