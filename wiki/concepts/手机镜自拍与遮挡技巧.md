# 手机镜自拍与遮挡技巧

> 本页总结真实生活手机镜自拍（Mirror Selfie）的核心构图法则、手机防畸变指令与局部动作微调方法。

> **证据更新（2026-10-08）**：本页“黄金”“防畸变”等措辞是历史方法表述，未有稳定复现证据；“严禁一次性重写”等表达是使用建议。已知图片观察与待验证效果见 [[wiki/maps/生图实战案例目录.md]]，原始动作文本与候选复用片段见 [[wiki/concepts/实战案例提示词片段库.md]]。不同案例的单眼可见、半脸露嘴角和双手遮脸边界应分别选用。

> **矛盾 / 更新（2026-10-15）**：露眼不再作为所有镜自拍的通用要求。新增手机完全遮脸模式，与单眼、双眼及局部遮挡模式互斥；新动作与投影关系只是候选设计，图片测试未执行，页面暂记needs-review。需求与事实来源见 [[wiki/sources/2026-10-15 - 手机完全遮脸姿势分支设计依据.md]]，1012归档及F12/F13原模式保留。

## 1. 手机相机模组的防畸变法则（黄金规整指令）

在日常镜自拍中，手机背面朝向镜子，往往直接占据画面中心。若提示词未加严格约束，AI 极易自动生成怪异的“三个等大黑色圆环”、“四个镜头”、“不合理闪光灯排列”等严重的 AI 幻觉假象。

### 推荐正向规整词

以下双摄款式只在底图确为该结构或任务明确指定时使用。姿势编辑默认沿用底图手机，不为了复用本段替换型号、壳体颜色或镜头排列。

```text
手机背部为小型圆角方形双摄模组，严格只有两颗大型黑色圆形摄像头，呈斜对角排列，黑色大镜头数量必须恰好为2；模组内另有极小的浅色闪光灯圆点，与镜头尺寸和颜色明显不同。
```

### 推荐强制负向词
```text
绝对不要出现第三颗摄像头，不要三摄，不要三个等大黑色圆环，不要生成 Pro 系列三摄相机模组，不要镜头变形。
```

## 2 手机面部遮挡模式与视线引导

先为同一张结果选择一种遮挡模式，再按该模式写手机投影、头部方向与可见范围。“不露全脸”不能替代具体边界，也不自动等于完全遮脸。下列模式是各自的候选目标，没有一套通用于所有案例。

| 模式 | 手机与面部目标 | 对应入口 | 与完全遮脸的关系 |
|---|---|---|---|
| 单眼可见 | 手机挡大部分脸，一只眼与局部镜框露出；原“半遮面黄金位 / 留白透光”只属于本模式 | [[wiki/concepts/实战案例提示词片段库.md#F03 镜自拍遮挡与视线]]及原F08 | 不叠加；删除“一只眼睛必须可见” |
| 双眼可见、遮嘴下巴 | 手机反射上缘低于双眼，嘴与下巴不可见，上半脸及眼镜露出 | [[提示词/02-提示词模板/GPT Image提示词模板/手机遮挡脸部.md]]、F08-A～D | 不叠加；删除上缘低于眼睛、眉眼清晰与不挡双眼 |
| 双眼可见、局部遮挡 | 约35%–45%为近似目标，仅遮一侧脸颊及部分下半脸，不超过半脸 | [[wiki/concepts/实战案例提示词片段库.md#1012 坐姿片段组合边界]]、F12/F13 | 不叠加；删除比例、上半脸可辨、禁止挡整脸等限制 |
| 露眼与嘴角等案例边界 | 沿具体案例保留一眼及嘴角，不能统一替换成遮嘴 | F07的0926版本 | 不叠加；不得露眼或嘴角 |
| 双手持机、大部分遮脸 | 双手同时握机，可留少量轮廓，不规定整脸完全遮住 | [[wiki/concepts/实战案例提示词片段库.md#F11 商场试衣与层叠遮挡]] | 不整段复用；F14须保留一只空手执行各自动作 |
| 手机完全遮脸 | 手机真实投影覆盖额头至下巴及左右面部外缘，双眼、鼻、嘴和下巴均不可见；头发、耳朵可见不等于露脸 | [[wiki/concepts/实战案例提示词片段库.md#F14 手机完全遮脸动作分支]] | 独立选择；不以露眼证明身份，不追加局部遮挡模板 |

### 可复用与必须排除的约束

| 约束 | 完全遮脸分支的处理 |
|---|---|
| 原持机手、屏幕朝本人、手机背部朝镜、握持与反射连续 | 可复用；画面左右按底图，不臆定身体左右手；持机手不兼做空手动作 |
| 底图身份、自然比例、服装设计、场景布局和原光源 | 可复用为编辑目标；衣褶、发丝落点、取景和投影允许姿势必需的变化，不冻结全部像素 |
| 不补画被遮五官、不把手机穿进脸、不加多余人物或手机、不用涂抹蒙版遮脸 | 可复用；完整遮挡只能来自本次手机投影，不能加贴纸、遮脸手掌或头发来补足 |
| 底图手机外观、相机模组结构 | 可复用；F06或本页双摄示例仅在底图匹配时使用，不强加双摄、颜色或机型 |
| “看手机屏幕” | 只保留为头部与操作意图；眼神被遮，不检验瞳孔方向，不加“可见眼睛清晰” |
| 单眼、双眼、眉眼、上半脸或嘴角必须可见 | 必须排除；手机完全遮脸与这些正向可见要求互斥 |
| 35%–45%、不超过半脸、手机上缘避眼、禁止遮住双眼或整脸 | 必须排除；不能保留在负向提示词、JSON约束或粘贴的旧模板尾段 |
| 原姿势、头部方向、手机位置和全部构图像素不动 | 必须释放必要部分；本次授权姿势与遮挡编辑，不允许据此重设计环境或扩图 |
| 被挡五官“清晰可辨”“已验证同脸” | 必须排除；记为不可验证。发型、体量、配饰和衣服仅能支持可见外观连续性 |

### 完全遮脸的几何与身份边界

“把手机靠近脸中央”并不保证能挡住整脸。手机实体尺寸不变时，需要在手臂舒适可达且不碰镜面的范围内，让手机较脸更靠近镜面，并协调头机位置，使其镜中投影覆盖脸部上下与两侧。不能一边锁死手机坐标和头部，一边要求从局部遮挡变为完整遮挡；不能靠缩头、瘦脸、放大手机实体或扭曲反射实现。

头部朝向屏幕并随动作舒适微调，避免侧转后从手机边缘露出另一只眼、鼻尖或下巴。手机与脸之间有真实空间，不贴脸、不穿模；持机臂与手机下降、前伸造成的有限透视变化属于必要联动。若底图镜距、手臂可达范围或裁切不支持本目标，记录输入不适用，不虚构已满足全部条件。

完整遮挡时，五官、表情、瞳孔方向及完整面部一致性都不可验证；“保持原人物”仍是编辑目标，验收只比较实际可见的发型、外露镜腿、配饰、体量和服装，不据此证明不可见面部身份。不能为了验证一致性补出眼睛或面部。文字与图片证据分别记录于 [[wiki/workflows/完全遮脸镜自拍回归检查.md]]。

## 3. 局部动作微调链（姿态演化方法论）

当一套基础自拍需要延展时，每张仍从同一原始底图出发，保留身份、比例、衣服、场景与成像基准。下表适用于小幅动作；用户允许大幅变化时，可用 [[wiki/concepts/实战案例提示词片段库.md#F14 手机完全遮脸动作分支]] 的错步转身或半蹲，整体更新相关关节、手机、衣褶、接触和投影，不扩大为换人、换装或换景。选完全遮脸后，不再继承小幅动作中的露眼要求。

| 动作分支 | 核心指令 | 真实感要点 |
|---|---|---|
| **分支 1：单手浅插袋** | 空手浅插进同侧裤袋，大拇指露在外面，手腕自然放松。 | 重心略落单腿，肩膀与腰胯自然形成微弱高低落差（骨盆微倾）。 |
| **分支 2：整理耳侧碎发** | 空手抬到同侧耳旁，两三根指尖轻轻将一缕碎发顺向耳后。 | 头部朝整理侧微偏，手机小幅横移让出空间，侧腰与袖口产生自然拉扯褶皱。 |
| **分支 3：自然下垂放松** | 空手自然垂下，手掌轻贴大腿侧面，手指微屈。 | 腹部自然放松，柔软呼吸感，严禁刻意吸腹或强化假腹肌。 |
