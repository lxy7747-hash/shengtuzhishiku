# GPT Image 提示词模板集

> 来源类型：用户既有工作资料（`提示词/` 目录）。
> 本页是这批模板的结构化摘要，不是原文。原文保持不可变，复制粘贴请回到原文件。

## 一句话摘要

这是一批面向 GPT Image 的实战提示词集合，共同目标是把「AI 人像」做成**可信的真人手机摄影**：统一的负面约束（不拉腿、不瘦脸、不过度磨皮、不塑料皮肤）、统一的真实感词表，以及两种写法——人类可读的自然语言段落，与机器友好的分层 JSON schema。

## 反复出现的共性结构（事实）

跨文件复现的表达可归纳为四类：

1. **强制约束前置**：把「必须严格参考参考图 @Image」写成第一句，并紧接一串否定式约束。
2. **统一否定词表**：不要拉腿／不要瘦腿／不要瘦脸／不要缩小胯部／不要过度磨皮／不要塑料感／不要网红化／不要幼态化／不要改变年龄感／头身比例协调。
3. **真实感锚点**：毛孔、肤色不均、油光、轻微噪点、压缩痕迹、自然不对称、镜头透视。
4. **材质与反光分层**：对丝袜、针织、皮质等分别描述反光强度与透肤层次，并明确「不要乳胶／皮革／塑料膜感」。

## 失败模式（来自笔记中的负面约束，属用户既有经验）

- 身材漂移：拉长腿、缩小胯、削弱臀部体积、腰部不自然变细、肩过窄 → 破坏真实重心。
- 面部漂移：瘦脸、大眼、网红化、幼态化、过度磨皮、瓷娃娃皮肤 → 丢失真实感。
- 材质失真：丝袜呈现乳胶／皮革／塑料膜的镜面反光。
- 视线异常：同时写「看手机屏幕」与「直视镜头」会导致眼球方向冲突（已在 [[提示词/02-提示词模板/GPT Image提示词模板/手机遮挡脸部.md]] 显式记录）。

## 可复用变量

主体角色、身材基线、服饰与材质、场景与空间深度、光源方向与光质、景别与视角、色彩倾向、输出比例（如 9:16）、后处理诉求（去噪点／保留颗粒）。
