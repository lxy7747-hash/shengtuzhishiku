# 手机遮挡脸部

## 正向提示词

```text
【下半脸遮挡为强制构图要求】

保持人物头部位置和视线基本不变，仅调整持手机手臂与手机的位置。

将手机向人物脸部中央轻微移动并降低，使手机真实位于下半张脸正前方。

手机顶部边缘落在鼻尖下方、上唇上方附近，手机机身完整覆盖嘴唇、嘴角、口周区域以及下巴。

嘴唇和下巴必须完全位于手机后方，在最终画面中不可见，不允许从手机左右两侧或底部露出。

双眼、眉毛、额头、眼镜、鼻梁及鼻部上半区域保持完整、清楚、无遮挡。

最终画面只能看到上半张脸，不能出现完整无遮挡全脸。

遮挡必须是手机与脸部之间真实的前后空间遮挡关系，而不是模糊、擦除或重新补画完整人脸。

【眼神与视线】

人物头部位置基本保持不变。

双眼完整、清晰可见，视线自然落在自己手中的手机屏幕上，
眼球仅轻微向持手机一侧偏转，双眼焦点一致。

不要直勾勾看向镜头，不要明显看向画面外，
不要出现斜视、斗鸡眼或左右眼焦点不一致。

眼睑自然放松，眼神平静、克制，
呈现真实镜自拍时查看手机取景画面的自然状态。
```

## 眼神变体

### 双眼更正、更容易看清上半张脸

```text
头部保持基本正面，双眼平视，视线落在镜中手机屏幕附近，仅有非常轻微的侧向偏移。眼睛完整清晰可见，瞳孔位置自然，不明显斜视，不看向画面外。
```

### 看镜子里的自己

```text
人物透过镜子平视自己的眼睛，视线接近正前方，不看手机镜头。双眼自然聚焦于镜中自己的面部，眼神平静、放松。
```

### 接近直视观众

```text
双眼通过镜面自然看向手机摄像头附近，视线接近镜头方向，但不过度直勾勾凝视，保持轻微柔和的自拍眼神。
```

## 使用注意

- 默认优先使用“手机屏幕注视”，最符合手机遮嘴、遮下巴的自然镜自拍感。
- 不要同时写“看手机屏幕”和“直视前方 / 直视镜头”，避免互相冲突导致眼球方向异常。
- 保持头部基本正面，仅让眼球轻微偏向手机一侧，不要让整个头部跟着手机转。

## 适用分类

- 构图：下半脸遮挡、手机位置、前后空间关系
- 人物：眼睛、眉毛、鼻部上半区域保持可见，眼神自然
- 约束：嘴唇、口周、下巴不可露出
